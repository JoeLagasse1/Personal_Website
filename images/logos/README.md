## Logo Specifications

- **File Format**: PNG with transparent background
- **Color**: Preferably white or light-colored logos (CSS applies grayscale filter)
- **Size**: Approximately 200px height, variable width
- **Background**: Must be transparent
- **Quality**: High resolution for crisp display

## Quick Download Tips

1. Visit the source links above
2. Look for "Download PNG" or "Download Transparent PNG" option
3. Save the file with the exact filename shown (e.g., `stm.png`)
4. Place the file in this directory (`images/logos/`)
5. Refresh your browser to see the logo in the carousel

## CSS Applied Effects

The carousel applies the following CSS effects automatically:
- Grayscale filter (100%)
- Reduced brightness (60%)
- Reduced opacity (70%)
- On hover: Full color, full brightness, full opacity
- Smooth transitions

This creates a professional, cohesive look regardless of the original logo colors.
